# The dual function hypothesis in male human faces

Replication package for **“The dual function hypothesis in male human faces. The relationship between fluctuating asymmetry and facial masculinity with third-party perception of fighting ability and attractiveness”**.

**Work in progress:** This project is ongoing. The analyses and replication materials are not yet finalized and may change.

## Replication materials

The replication package is being prepared. Analysis code, supporting files, software requirements, and instructions for reproducing the results will be added as they become available. Scripts may be examined but data will not be made available until manuscript submission.
